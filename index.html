What It Does

🔍

Full-Text Book Search

Search 5,000 books by any combination of title, author, or ISBN using SQL LIKE queries with partial matching.

⭐

Star Ratings & Reviews

Authenticated users post one review and a 1–5 score per book. All reviews are aggregated on the book's detail page.

🌐

Google Books Enrichment

Each book page fetches live average rating and ratings count from the Google Books API and displays it alongside local reviews.

📋

JSON REST API

GET /api/<isbn> returns book metadata plus review count and average score — consumable by any external app or script.

Database Schema

-- Three tables with FK constraints
Books    (BookID, ISBN, Title, Author, Year, Created, Modified)
Users    (UserID, Username, Password, Created, Modified)
Reviews  (ReviewID, PostedBy → Users, ReviewOf → Books, Review, Score, Created)

-- One review per user per book enforced at query level
-- 5,000 books seeded from books.csv via db/import.py
